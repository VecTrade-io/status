# Contributing to VecTrade Status

Thank you for your interest in contributing to VecTrade Status!

## How to Contribute

### Reporting Issues

- Use [GitHub Issues](https://github.com/VecTrade-io/status/issues) to report problems
- Include the affected service and time of issue

### Adding Monitored Services

1. Fork the repository
2. Edit `.upptimerc.yml` to add/modify monitored sites
3. Submit a Pull Request

### Development

This repository uses [Upptime](https://upptime.js.org) for automated monitoring.
The workflows are auto-generated — do not edit workflow files directly.
