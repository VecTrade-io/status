# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

- **Email**: security@vectrade.io
- **Do NOT** open a public GitHub issue for security vulnerabilities

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Scope

This repository monitors VecTrade service uptime. Security concerns related to
the monitored services should be reported to the respective service owners.
