# VecTrade Status

This repository uses [Upptime](https://upptime.js.org) to monitor VecTrade services and generate a status page hosted at [status.vectrade.io](https://status.vectrade.io).

## Monitored Services

| Service | URL |
|---------|-----|
| VecTrade | https://vectrade.io |
| VecTrade UAT | https://uat.vectrade.io |
| Documentation | https://docs.vectrade.io |
| API | https://api.vectrade.io |

## How it works

- GitHub Actions runs every 5 minutes to check uptime
- Response time graphs are generated every 6 hours
- Status page is rebuilt daily
- Issues are automatically created when a service goes down
